# Clientes de Connie

Una carpeta por cliente: `clientes/<nombre>/estado.md`.

Cada `estado.md` lleva: quién es, qué trabajo hay en curso, qué quedó pendiente
y con qué fecha, y las decisiones que ya se tomaron (para no volver a
preguntarlas).

Se **lee antes** de retomar algo de ese cliente y se **actualiza al cerrar**.
