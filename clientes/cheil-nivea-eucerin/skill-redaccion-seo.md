## 0. Pipeline de redacción (blog)

### Mini-briefing — preguntar antes de redactar

Antes de escribir una sola palabra, hacer las siguientes preguntas. **Sin estas
respuestas no se inicia la redacción:**

1. ¿Cuál es la **keyword principal**?
2. ¿**Cuántas palabras** quieres? → Ver tabla de extensión abajo. Nunca menos de 600.
3. ¿Cuál es el **país objetivo**? → Define el estilo: España («vosotros») o
   Latinoamérica («ustedes»). ¿Se menciona el país explícitamente en el texto o
   se evita?
4. ¿Cuál es el **tono de voz**? → Formal, cercano, técnico, divulgativo. Si no se
   especifica, analizar la web del cliente y replicar el tono que ya usa.
5. ¿Hay **palabras o términos prohibidos**? → El cliente puede tener una lista de
   términos a evitar (competidores, palabras sensibles, tecnicismos). Solicitarla
   antes de redactar.
6. ¿Se incluyen **CTAs**? → Si la respuesta es sí: ¿a qué página / servicio /
   categoría deben apuntar?
7. ¿Hay un **H1 ya definido** o debe sugerirse?
8. ¿Hay **artículos relacionados** del blog que incluir como «Lee también»?

### Paso 1 — Investigación

Con el briefing resuelto, recopilar **antes** de redactar:

- Intención de búsqueda real de la keyword.
- Estructura sugerida de H2/H3 basada en el **top 10 de Google**.
- Datos, estadísticas y ejemplos concretos.
- Ángulo diferenciador respecto a lo que ya existe.
- FAQs reales (3-5 preguntas que hace la gente).
- Entidades y palabras relacionadas del top 10.

### Paso 2 — Redacción

Usar la investigación del Paso 1 como base. **No redactar «a ciegas».**

#### Tabla de extensión recomendada

| Longitud objetivo | Cuándo usar |
|---|---|
| 600–800 palabras | Nota rápida, keyword de baja competencia |
| 900–1.200 palabras | Artículo estándar, keyword de competencia media |
| 1.300–1.800 palabras | Artículo profundo, keyword competida |
| 1.800–2.500 palabras | Pilar de contenido, alta competencia |
| 2.500+ palabras | Contenido de autoridad / pilar central del blog |

Si el cliente no especifica, **recomendar según la competencia de la keyword**.
**Mínimo absoluto: 600 palabras.**

## 1. Reglas comunes a todos los tipos de página

### Regla base — dónde siempre debe estar la keyword principal

La keyword principal debe estar presente en estos **4 campos sin excepción**:

| Campo | Por qué importa |
|---|---|
| **H1** | Es el título visible de la página — señal principal para Google y para el lector |
| **Metatítulo** | Es lo que aparece en los resultados de Google — debe contener la keyword para que el usuario conecte su búsqueda con el resultado |
| **Metadescripción** | Refuerza la relevancia en el SERP y mejora el CTR — la keyword debe ir **al inicio** |
| **Slug / URL** | Google la lee como señal de tema — una URL con la keyword posiciona mejor que una genérica |

Si la keyword no está en alguno de estos 4 campos, la página tiene una **brecha
de optimización básica**.
